# jniLibs — populated by the build, never committed

`scripts/build-android.sh` writes the Go c-shared libraries to
`bind/capi/build/android/jniLibs/<abi>/libpress.so` for four ABIs
(`arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`).

`scripts/vendor-dart-native.sh` copies them here, which is where
`android/build.gradle` expects them (`main.jniLibs.srcDirs`).

The `.so` files themselves are excluded by the repository `.gitignore` — they
are build outputs, regenerated by CI (`.github/workflows/dart-native.yml`) or
locally. This README is what keeps the directory present in git.
