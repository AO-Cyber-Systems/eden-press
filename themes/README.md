# themes/

Vendored Marp assets (the `default`, `gaia`, and `uncover` themes plus the browser
fit/polyfill script) land here in **Objective 3** under their original **MIT license** and
**Marp copyright** (`Copyright (c) 2018 Marp team (marp-team@marp.app)`), stamped with the
verbatim-asset header template documented in [CONTRIBUTING.md](../CONTRIBUTING.md).

This directory is **empty by design in Objective 0** — Eden Press bootstraps the licensing and
attribution mechanism *before* any vendored engine or theme asset exists, so attribution is a
standing, CI-enforced mechanism rather than a one-time file write. Do not add theme assets here
until Objective 3 (CORE-01); when you do, the per-PR NOTICE-update checklist and
`addlicense -check` gate apply.
