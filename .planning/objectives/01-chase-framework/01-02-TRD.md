<objective>
Build `chase/directive` — the pure directive resolution engine: HTML-comment + YAML front-matter detection (PARSE-03), and the global/local/spot carry-forward state machine (PARSE-02). ZERO goldmark import — it operates on plain strings and ordered events, exactly like Marpit's `directives/*.js` operate on comment-content strings before any token exists. This is the parallel sibling of `chase/theme` (no shared dependency) and the dependency `chase/markdown` imports.

Purpose: Marpit's directive semantics (carry-forward, spot single-slide scoping, silent-drop of unknown themes, per-directive value coercion) are custom and load-bearing for byte-exact corpus HTML. Isolating them as a pure package keeps `chase/markdown` free of directive logic and makes the state machine table-testable on its own.

Output: `chase/directive/` package: comment detector, front-matter parser, YAML-ish value parser, directive tables + coercion, and the cursor state machine — all unit-tested against the corpus's directive cases.
</objective>

<anti_patterns>

A non-directive comment must still be detected (and later kept hidden), not stripped.

</anti_patterns>

<research_context>
From 01-RESEARCH.md §"chase/directive carry-forward state machine" (verbatim from parse.js) and §"Directive value coercion tables":
- cursor = {slide, local:{}, spot:{}}. On slide OPEN: reset per-slide directives, set cursor.slide. On slide CLOSE: merge `{...local, ...spot}` onto the slide, then `spot = {}`. On directive comment: for each key, if `locals[key]` merge into `local`; if key starts `_`, and `locals[key[1:]]` exists, merge into `spot`.
- Global directives resolve in a SEPARATE earlier pass and are stamped identically onto every slide at the end.
- Coercion: headingDivider int 1-6 → `[1..N]`, array of ints, or `"false"`→false; theme accepted only if theme-set has it (else silently dropped); paginate lowercased, hold/skip passthrough else `v==='true'`; class arrays join with space; header/footer only if already a string.
</research_context>

## Test list
(test_list_first required — write failing tests first; happy → edge → failure)

1. Front-matter `theme: gaia` → global directive `theme=gaia` (deck-level).
2. Comment `<!-- _class: lead -->` → raw kv `{_class: "lead"}` detected (not yet recognized).
3. Multi-line comment span detected; a line not starting with `<` fast-fails detection.
4. A non-directive comment (`<!-- just a note -->`) is DETECTED but produces no recognized directive.
5. Global coercion: `headingDivider: 2` → `[1,2]`; `headingDivider: false` → `false`; unknown `theme: nope` (predicate false) → dropped.
6. Local carry-forward: `class: a` on slide 1 persists to slide 2; overridden by `class: b` on slide 3.
7. Spot: `_class: lead` applies only to the current slide; slide+1 has no class from it (spot reset).
8. Local coercion: `paginate: hold`→"hold"; `paginate: true`→true; `class: [a, b]`→"a b"; non-string `footer` rejected.
9. Global stamped on every slide identically after the local/spot loop.
