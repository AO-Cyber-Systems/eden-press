<objective>
Build the full ordered theme-CSS scoping pipeline (THEME-03) as a two-tier design over the 01-03 Stylesheet model and the 01-01 selector subsystem: `Theme.Load` (Tier-1 add-time, run once per theme) and `ThemeSet.Pack` (Tier-2 render-time, run every render). This is the CSS half of Objective 1's value-add and the highest-risk sub-part (native nesting down-leveling has no Go analogue).

Purpose: Marpit's real pass order (verified line-for-line from theme_set.js/theme.js) is NOT a single linear scope-then-resolve pipeline (RESEARCH Pitfall 1). It is two tiers with `:root` replaced twice and the specificity boost deferred until AFTER scoping. Getting the order wrong produces structurally-correct but wrong-cascade CSS. This TRD implements the exact order and proves it with cssdiff.Equal.

Output: `chase/theme/{theme.go, pack.go, pass_*.go, scaffold.go}` + a cssdiff-gated pipeline test suite.
</objective>

<anti_patterns>

- DO NOT assume tdewolff flattens nesting (RESEARCH Pitfall 2). It only tokenizes nested syntax; you must flatten. Scope the flattener to what the stress theme + scaffold need — NOT general CSS Nesting Level 1 compliance.
