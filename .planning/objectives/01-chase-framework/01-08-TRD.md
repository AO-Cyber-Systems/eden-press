<codebase_examples>
The two-phase seam, verified from goldmark v1.8.4 (RESEARCH §"Two-Phase Render Seam") — Convert() is LITERALLY Parse() then Render(); call the two steps directly so the AST is inspectable between them:

```go
reader := text.NewReader([]byte(md))
pc := parser.NewContext()
doc := engine.Parser().Parse(reader, parser.WithContext(pc))
// >>> doc (ast.Node) and pc (parser.Context) are BOTH inspectable HERE <<<
var buf bytes.Buffer
if err := engine.Renderer().Render(&buf, []byte(md), doc); err != nil { return "", err }
```
