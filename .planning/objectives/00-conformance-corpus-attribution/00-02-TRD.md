func normalize(fragment string) (string, error) {
    ctx := &html.Node{Type: html.ElementNode, Data: "body", DataAtom: atom.Body}
    nodes, err := html.ParseFragment(strings.NewReader(fragment), ctx)
    if err != nil { return "", err }
    var sb strings.Builder
    for _, n := range nodes { walk(&sb, n, false) }
    return sb.String(), nil
}

// walk: sorts attributes alphabetically; collapses inter-block whitespace via strings.Fields;
// preserves <pre>/<code> text verbatim (inPre flag); serializes a canonical token stream.
// Full source in md-spike/main.go lines 56-101.

## Test list

Behavior cases to cover, written BEFORE the test code (outermost cosmetic-equivalence to
innermost verbatim-preservation), per test_list_first=required:

**htmldiff (happy — cosmetic equivalence):**
- Identical fragments compare Equal.
- `<br>` vs `<br/>` vs `<br />` compare Equal (void-element syntax — named assertion).
- `<hr>` vs `<hr/>` compare Equal.
- Attribute order differences (`<a href="x" title="y">` vs `<a title="y" href="x">`) compare Equal.
- Inter-block whitespace / newline differences between block elements compare Equal.

**htmldiff (edge / failure — the allow-list must NOT over-reach):**
- NEGATIVE: a code span whose inner text changed (`` `a<b` `` vs `` `a>b` ``) compares as DIFF.
- NEGATIVE: `<pre>` content with an altered leading-space / changed line compares as DIFF
  (whitespace-significant inside pre/code).
- NEGATIVE: a genuinely different element (`<em>` vs `<strong>`) compares as DIFF.
- NEGATIVE: differing attribute VALUES (not just order) compare as DIFF.

**corpus loader:**
- Loads a case dir with input.md + options.json + expected.html into a Case with fields populated.
- Loads the optional expected.css when present; leaves it empty when absent.
- Surfaces a clear error for a malformed/missing required file.

**report aggregator:**
- Add(section, pass) then Render() shows per-section pass/total (e.g., "Lists: 12/13").
- Summary() returns aggregate pass/total AND the count of sections with any failure.
- An empty report renders without panicking.
