## What was built

A language-neutral **golden corpus** of Marp cases, generated by rendering representative
Markdown through the **real `@marp-team/marp-core` v4.4.0** (the npm oracle) — the ground truth
an Eden Press marp-core-equivalent engine must reproduce. Marp ships essentially no `.snap`
golden files (00-RESEARCH.md), so rendering through the actual package is the correct extraction.

- **`tools/corpus-gen/`** (dev-only, not shipped): `package.json` (`@marp-team/marp-core ^4.1.0`,
  resolved 4.4.0) + `gen.mjs`. `node gen.mjs` renders each case through `new Marp({ script: false })`
  and writes `conformance/corpus/cases/<id>/{input.md, options.json, expected.html[, expected.css]}`.
- **18 golden cases** covering Marpit + Marp Core behavior: basic, slide-split, headingDivider,
  paginate, header/footer, spot `_class`, background image / split / color, themes gaia + uncover,
  size 4:3, math, emoji, code-highlight, GFM table, strikethrough, fit-heading. Theme/size cases
  also carry `expected.css`; HTML-focused cases stay lean (expected.css is optional).
- Each case declares `options.json → requires_engine: "marp-core"`.
- **`conformance/runner/corpus_test.go`** (`TestMarpCorpus`): loads via `corpus.LoadCases`, asserts
  every case is well-formed, and — because the Marp engine does not exist in Objective 0 — marks
  each case **PENDING** via `report.AddPending` (neither pass nor fail). Objective 3 reruns this
  exact corpus for real once `press.Render` exists.
- **`NOTICE`**: Marp-corpus block filled (marp-core v4.4.0 / marpit, MIT, 18 cases, regen command).
- **`.github/workflows/ci.yml`**: addlicense gate now `-ignore 'conformance/corpus/cases/**'` — the
  Marp-derived golden data must NOT carry Eden Press's copyright (provenance is in NOTICE); reconciles
  CONF-01's vendored data with LIC-03's header enforcement.
