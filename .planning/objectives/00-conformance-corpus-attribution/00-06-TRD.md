## Test list

Per test_first=required — behavior cases for the CSS-AST comparator (outermost equivalence to
innermost regression detection):

**equality (happy):**
- Two identical stylesheets → equal, empty report.
- Two stylesheets differing ONLY cosmetically (whitespace, `#FFF` vs `#ffffff`, single vs
  double quotes, a stripped comment) → equal (normalized away by the 00-03 model).

**regression detection (the CONF-03 negative tests — MUST fail):**
- A changed property VALUE (`color: red` → `color: blue`) → DIFF, report names the property.
- A dropped `!important` → DIFF.
- A changed selector (class renamed / specificity-relevant change) → DIFF.
- An added or removed declaration → DIFF.

**order-sensitivity (the Pitfall-3 guard — MUST fail on reorder):**
- Two same-property declarations REORDERED (swap which comes last) → DIFF (cascade-significant).
- Two rules reordered → DIFF.
