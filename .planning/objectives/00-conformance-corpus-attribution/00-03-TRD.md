<objective>
De-risk the single novel / highest-uncertainty item in this objective: the CSS-AST diff
model. `tdewolff/parse/v2/css` exposes a grammar-TOKEN stream, not a typed AST — there is no
off-the-shelf Go CSS-AST diff library — so Eden Press must build its own thin, normalized
Stylesheet/Rule/Declaration model on top of the grammar stream before any diffing is
possible. This TRD is that spike: build the model + the grammar-stream→model builder, and
prove (exit criterion) that a mutated declaration is detectable in the model. The full
comparator + rigorous theme negative tests land in 00-06.

Purpose: RESEARCH flags CONF-03 as LOW-confidence/novel and explicitly recommends spike-
first. Sequencing this small spike before the comparator retires the uncertainty on a small,
timeboxed surface rather than discovering it mid-comparator.

Output: conformance/cssdiff/{model.go, build.go, spike_test.go} — the normalized model and
the tdewolff-grammar-stream builder, with a passing detectability spike test.

type Declaration struct {
    Property  string
    Value     string
    Important bool
}
type Rule struct {
    Selector     string
    Declarations []Declaration
    AtRule       string   // "" for a plain ruleset; e.g. "@media (...)" when at-rule context is present

    Rules []Rule
    // At-rule handling (@media/@keyframes) deliberately minimal in v1 — extend when the
    // theme-CSS engine objective's actual at-rule usage is known (00-RESEARCH.md Open Q2).
}

## Test list

Per test_first=required — behavior cases proving the model + builder + detectability:

**build → model (happy):**
- A single rule `a { color: red; }` parses to one Rule, selector "a", one Declaration {color, red, false}.
- Multiple declarations preserve source ORDER.
- `!important` is captured as Declaration.Important = true and stripped from Value.
- Multiple rules preserve source ORDER.

**within-node normalization (edge):**
- `#FFF` and `#ffffff`-style hex values lowercase to canonical form.
- Redundant whitespace in selector and value collapses.
- Comments are stripped from the model.
- Single vs double quotes normalize to one canonical style.

**detectability (spike EXIT CRITERION — failure-to-match):**
- Parse a CSS snippet; parse a copy with ONE declaration value changed; the two Stylesheet
  models are NOT deeply equal (mutation is detectable at the model level).
- Parse a CSS snippet; parse a copy with two same-property declarations REORDERED; the two
  models are NOT deeply equal (order is preserved and therefore detectable).
