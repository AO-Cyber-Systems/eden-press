- `writePPTX(cmd, out)`: calls `pptx.ToPPTX(out.Model, pptx.Options{})` — `out.Model` is already `*chase/model.Document` (typed by `press.Render`), passed straight through, so `cmd/eden-press` never imports `chase/model` directly — then writes the returned bytes via `writeOutputBytes` (the same `--output`/`-o`-or-stdout sink `writeJSON` uses). `emitFormat`'s `pptx` case now dispatches to it instead of the 04.1-01 not-yet-wired usage-error placeholder.
- `scripts/check-no-chromedp.sh`: `TREES` now includes `./cmd/...` alongside `press/`, `chase/`, `profiles/`, `bind/` — the CLI's "stays chromedp-free" property is now a CI-enforced mechanical gate, not an unenforced intention. Verified 0: the transitive closure of `./cmd/...` (now including `convert/pptx` + `chase/model`, both chrome-free) contains zero chromedp.
- `scripts/check-cli-imports.sh` deliberately left **byte-for-byte unchanged** — `convert/pptx` never matches its `(chase|profiles)|chromedp` grep on `cmd/eden-press`'s own direct imports, so OBJECTIVE.md deliverable 5 ("relax check-cli-imports.sh") is confirmed unnecessary and NOT performed, per the TRD's own reconciliation note.
- `AGENTS.md` (repo root): documents the three `--format` values (html default/json/pptx), the full JSON envelope schema (spelling out that a code block's raw source AND a math block's raw TeX both live in `block.text`, with `language`/`display` alongside — no `source`/`tex` keys), the exit-code table (0 ok/1 render/2 usage), the `{"error":{"code","message"}}` stderr envelope gated on `--format json`, and copy-paste examples.
- `cmd/eden-press/agent_interface_test.go`: `TestAgentFormatPPTXValidZip` (file `-o`, asserts `[Content_Types].xml` + `ppt/presentation.xml` present via `archive/zip`), `TestAgentFormatPPTXStdout` (no `-o`, stdout leg is still a valid zip), `TestAgentFormatJSONEndToEnd` (re-proves 04.1-01's envelope contract through this TRD's own front-matter-bearing fixture and the newly-wired pptx sibling case), `TestAgentGateEnforcement` (runs both shell gates as real scripts), and `TestAgentExecBadInputExitCode` (a REAL subprocess — `go build` + `exec.Command`, not an in-process cobra call — proving `main.go`'s actual `os.Exit(1)` + JSON error envelope on stderr for a bad input).
- Manually verified end-to-end: `go run ./cmd/eden-press convert deck.md -o out.pptx --format pptx` produced a 16-part valid OOXML zip (Python `zipfile` parse confirmed `[Content_Types].xml` + `ppt/presentation.xml` present); `go run ./cmd/eden-press /no/such.md --format json` printed the JSON error envelope to stderr and exited 1.
