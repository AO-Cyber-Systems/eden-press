# Objective 4.1 TRD 01: format.go — JSON envelope + machine-readable error contract Summary

**The Chrome-free agent JSON surface: `--format json` emits the full `press.Output` as a lowercase-keyed envelope with the schema-v2 model verbatim (no browser needed to inspect deck structure), plus a stable exit-code contract (0/1/2) and a JSON error envelope on stderr — all routed through one dispatch seam (`emitFormat`) and one failure sink (`cliFail`), with `cmd/eden-press` still never importing `chase/model` directly.**

## Accomplishments
- `jsonEnvelope{html,css,model,comments,meta}` (format.go): the lowercase-keyed JSON view of `press.Output`; `Model`/`Meta` are typed `any`, fed `out.Model`/`out.Meta` — marshals via `model.Document`'s OWN json tags (schema-v2 verbatim: `{kind:"code", text:<raw source>, language}` / `{kind:"math", text:<raw TeX>, display}`, NO renamed `source`/`tex` keys), while `cmd/eden-press` imports only `press/` + stdlib + cobra/koanf.
- `cliError{code,err,printed}` + `cliFail(cmd,code,err)`: the single failure sink. When `--format json` is active it emits `{"error":{"code":<int>,"message":<string>}}` to stderr and marks `printed:true`; otherwise it defers plain-text printing to `main`. Both `runConvert`'s pre-emit error returns and `emitFormat`'s own failure paths (unknown format, not-yet-wired pptx) route through it.
- `emitFormat(cmd,out)`: the single format-dispatch seam — `html` (unchanged `assembleHTML`+`writeOutput` path), `json` (`writeJSON`), `pptx` (usage-error stub for 04.1-02 to fill), default (unknown-format usage error).
- `--format` wired as a PERSISTENT flag (`html` default | `json` | `pptx`) in `registerPersistentFlags`, so both the bare root default and the explicit `convert` subcommand resolve it identically via `cfg.String("format")`.
- `main.go`/`root.go`: `main` is now the SOLE exit-code sink (`errors.As(*cliError)` -> `os.Exit(code)`, printing only when `!printed`); `root.go` sets `SilenceErrors: true` + a `FlagErrorFunc` that wraps every cobra/pflag flag error as `cliError{code: exitUsage}` — so cobra never double-prints and an unregistered flag maps to exit 2, proven by `TestEndToEndFlagErrorIsUsageError`.
- Exit-code contract (0 ok / 1 render / 2 usage) proven BOTH by unit/integration tests and by manual CLI invocation (see Verification below) — including the TRD's own literal `printf | go run ... | python3 -c '...assert...'` example.
- Objective 4's CLI-01..04 behavior is byte-identical and zero-regression: the html default path (`assembleHTML`/`writeOutput`) was left untouched, and the whole pre-existing `./cmd/eden-press/...` suite (convert/integration/watch/serve/preview) stays green.
- `check-cli-imports.sh` and `check-no-chromedp.sh` both stay PASS with zero changes to their scope — `chase/model` is never imported, directly or (deliberately, by choice) even in test files.
