<objective>
Deliver the native build recipes (DART-02): `-buildmode=c-shared` per Android ABI (`.so`) and `-buildmode=c-archive` per iOS arch (`.a` → universal via `lipo` → `.xcframework`), plus a CI workflow that verifies Android and iOS as two separately-toolchained, environment-isolated pipelines — with **no `gomobile bind`** anywhere.

Purpose: `dart:ffi` consumes a C ABI directly, so the native binding is just cross-compiling the 07-01 cgo shim per target ABI/arch (RESEARCH §2). gomobile bind is rejected (unneeded JNI/ObjC stubs + its own toolchain-panic bug class, RESEARCH Pitfall 5). The objective's SC#2 requires CI to prove both pipelines succeed, specifically on an Apple-Silicon runner that also has the Android NDK present (the corrected env-isolation hygiene case, RESEARCH §2).
Output: `scripts/build-android.sh` + `scripts/build-ios.sh` + `.github/workflows/dart-native.yml`.
</objective>

<codebase_examples>
The cgo shim these recipes cross-compile (07-01, bind/capi, package main). The existing ci.yml (untouched by this TRD) shows the house style — a NEW workflow file is added rather than editing ci.yml, to avoid churn and keep the native lanes isolated. Android recipe (RESEARCH §2 — verify the actual NDK's clang path before pinning; it varies by NDK version):
```bash
export NDK_BIN="$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/<host-tag>/bin"
CGO_ENABLED=1 GOOS=android GOARCH=arm64 \
  CC="$NDK_BIN/aarch64-linux-android21-clang" \
  go build -buildmode=c-shared -o android/jniLibs/arm64-v8a/libpress.so ./bind/capi
# repeat: armeabi-v7a (armv7a-linux-androideabi21-clang, GOARCH=arm GOARM=7),
#         x86_64 (x86_64-linux-android21-clang), x86 (i686-linux-android21-clang)
```

iOS recipe (RESEARCH §2 — device arm64 shown; add sim arm64/x86_64 the same way, then merge):
```bash
CGO_ENABLED=1 GOOS=darwin GOARCH=arm64 CC=$(go env GOROOT)/misc/ios/clangwrap.sh \
  CGO_CFLAGS="-fembed-bitcode" \
  go build -buildmode=c-archive -tags ios -o build/ios-arm64/libpress.a ./bind/capi
lipo -create -output libpress.a build/ios-arm64/libpress.a build/ios-sim-arm64/libpress.a build/ios-sim-x86_64/libpress.a
```
