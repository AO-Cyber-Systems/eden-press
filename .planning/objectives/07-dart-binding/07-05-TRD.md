FFI memory round-trip (RESEARCH §1 — the pattern, not prescribed code):
```dart
final reqPtr = jsonRequest.toNativeUtf8(allocator: arena);   // Dart owns the INPUT
final outPtr = _pressRender(reqPtr.cast());                  // Go returns C-heap OUTPUT
final resp   = outPtr.cast<Utf8>().toDartString();           // COPY out (toDartString copies)
_pressFree(outPtr);                                          // release Go's C-heap output
// arena disposal frees reqPtr — never call free on outPtr with Dart's allocator
```

- `kind` ∈ {`text`, `code`, `math`}

- ordering preserved so the surface renders blocks in document order
