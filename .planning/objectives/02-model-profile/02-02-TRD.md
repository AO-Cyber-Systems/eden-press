<objective>
Ship `chase/profile`: the output-profile abstraction (differentiator #1) as its own first-class package on day one. A `Profile` owns everything that differs between "Marp slides," "paged report," "article," and "EPUB" — and NOTHING else. Parsing, directive resolution, the model, and the theme-CSS scoping PASSES are all profile-agnostic; a profile only supplies the tables/predicates those passes consult.

This TRD also RESOLVES the objective's decision gate: `chase/*` is EXPORTED (no `internal/` prefix), documented here, so `profiles/paged`/`article`/`epub` (and advanced external consumers) can import `chase/*` directly — the whole point of "library-first."

Purpose: Buy profile-2/3/4 for the cost of one interface + a registry, WITHOUT over-abstracting for a v1 that only needs one profile. The interface is written FROM what `profiles/slides` actually needs (bottom-up, 02-03), never a speculative superset built before a second profile exists to validate it.
Output: `chase/profile` package (interface + registry + decision doc), consumed by 02-03 and 02-04.
</objective>

The `Size` type already exists in `chase/theme/stylesheet.go` (`Size{Name string; WidthPx, HeightPx int}`). Reuse it — `chase/profile` may import `chase/theme` for `Size` (one-way; theme never imports profile). Suggested interface (finalize bottom-up in 02-03):

```go
package profile

type Profile interface {
    ID() string                              // "slides"
    UnitElement() string                     // "section" — the element theme rules scope onto
    Container(inlineSVG bool) string         // "div.marpit" / "div.marpit > svg > foreignObject"
    Sizes() SizeTable                        // named sizes + default (16:9 default for slides)
    Pagination() PaginationRule              // section::after counter shape
    Scaffold(inlineSVG bool) string          // slide-reset (+ advanced-bg) CSS to prepend
}
type SizeTable struct {
    ByName  map[string]theme.Size
    Default theme.Size
}
type PaginationRule struct { /* the render-time pagination CSS shape */ }
```

<anti_patterns>
- SPECULATIVE SUPERSET (the locked-decision warning): do NOT add `Boundary()`, `Directives()`, or any method that has NO consumer in this objective. ARCHITECTURE.md Pattern 2 sketches `Boundary`/`Directives` for FUTURE profiles, but slides' unit-splitting is already done by chase/markdown's transformer and slides adds no profile-only directives in v1 — so adding them now is exactly the over-abstraction the locked decision forbids. Add a method only when 02-03/02-04 has a call-site for it. Document the deferral in doc.go.
- Do NOT let `chase/theme` import `chase/profile` (would risk an import cycle, since profile may import theme for Size). The dependency edge is one-way: profile → theme. The de-hardcoded theme.Pack (02-03) takes PRIMITIVES/theme-types as parameters; the entrypoint (02-04) bridges profile → primitives.
- Do NOT introduce an `internal/` prefix anywhere under `chase/` — the resolved decision is EXPORTED.
</anti_patterns>
