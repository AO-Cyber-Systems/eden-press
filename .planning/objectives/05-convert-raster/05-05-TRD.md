<objective>
Close EXP-04's CI-hardening facet and join the wave-3 exporters into one hardened capstone: (1) an end-to-end integration test driving press.Render → pdf.ToPDF + png.ToImages through public surfaces only; (2) a CI job running the export tests in a PINNED chromedp/headless-shell container with NO system Chrome (proving the discovery fallback chain in a clean environment) with the Pitfall-11 launch hardening; (3) an explicit Chrome-version pin + a documented, enforced PDF-path re-validation process for version bumps; (4) proof the Obj-3 no-chromedp gate + addlicense gate stay green after the full convert/ build-out; and (5) operator docs (convert/EXPORT.md) for discovery + the STIX font requirement + the version process.

And because PDF and PNG use different Chrome subsystems with PDF-only regression precedents, the version-pin + PDF-re-validation discipline is a first-class process artifact, not a code comment.
Output: convert/export_integration_test.go + scripts/check-chrome-export.sh + a pinned no-system-Chrome CI export job + convert/EXPORT.md.
</objective>
