Create `convert/chrome/discover.go` with the EXP-04 discovery fallback chain, designed pure/injectable so it needs NO live Chrome to test:

```go
type DiscoverOptions struct {
    BrowserPath string                       // explicit override (highest precedence)
    getenv      func(string) string          // injected; defaults to os.Getenv
    lookPath    func(string) (string, error) // injected; defaults to exec.LookPath
}

// Discover resolves a Chrome executable path (or "" meaning "let chromedp
// auto-detect") plus a source label describing which tier won.
func Discover(opts DiscoverOptions) (execPath, source string, err error)
```

Precedence (05-RESEARCH Pattern 3), stop at first hit:
1. `opts.BrowserPath != ""` → return it, source="browser-path".
2. `getenv("CHROME_PATH") != ""` → return it, source="chrome-path-env". (CHROME_PATH is eden-press glue, NOT a chromedp built-in — read it here.)
3. lookPath finds any of {"google-chrome","chromium-browser","chromium","google-chrome-beta","google-chrome-unstable"} OR the terminal `/usr/bin/google-chrome` → return "" (empty ExecPath) + source="auto", deliberately delegating to chromedp's own ExecAllocator auto-detection rather than pinning a path.
4. nothing found → return "", "", `ErrChromeNotFound` — a sentinel error whose message documents the tier-4 remedy: pin a `chromedp/headless-shell:<tag>` image or fetch a build from Chrome-for-Testing's known-good-versions JSON (googlechromelabs.github.io/chrome-for-testing). EXP-04 requires this tier be DOCUMENTED, not automated in v1.

# CRITICAL: getenv/lookPath are struct fields defaulted (in a small constructor or a nil-check) to os.Getenv/exec.LookPath, so production uses the real ones and tests inject fakes.
# GOTCHA: tier-3 returns EMPTY execPath on purpose — chromedp's ExecAllocator auto-finds its own binary when no ExecPath option is given (05-RESEARCH Pattern 3 tier 3).

```go
type Session struct { /* holds the allocator ctx + cancel */ }

// New builds ONE chromedp ExecAllocator/browser with the CI-hardening +
// determinism launch flags baked in as defaults, using Discover to resolve
// the executable.
func New(opts convert.Options) (*Session, error)

// NewTab creates a child chromedp.NewContext — a new TAB on the SAME browser,

// Close tears the browser down.

```

New() must:
1. Call chrome.Discover(DiscoverOptions{BrowserPath: opts.BrowserPath}); on ErrChromeNotFound, return it (callers/tests skip).
2.
