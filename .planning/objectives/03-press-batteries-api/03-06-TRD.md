<objective>

The predicate detects the trigger classes cheaply on raw source. Do NOT over-scope math quality here.

</objective>

<codebase_examples>
No reusable library exists for the goldmark-integration layer — build a bespoke InlineParser (trigger `$`), a custom AST node, and a NodeRenderer, mirroring how `chase/markdown` builds its own inline parsers (e.g. `chase/markdown/inline_style.go`, `image.go`). The renderer routes via the predicate:

```go
package math

// mathNode is the custom AST node the $-parser emits; Raw is the LaTeX
// between the delimiters, Block distinguishes $$…$$ from $…$.
type mathNode struct { ast.BaseInline; Raw string; Block bool }

// render decides route on the RAW source, cheaply, before any conversion:
func (r *mathRenderer) render(w util.BufWriter, source []byte, n ast.Node, entering bool) (ast.WalkStatus, error) {
    if !entering { return ast.WalkContinue, nil }
    m := n.(*mathNode)
    if needsFallback(m.Raw) {            // detect.go — pre-scan predicate
        w.WriteString(renderFallbackIMG(m.Raw, m.Block)) // fallback.go — base64 PNG <img>
    } else {
        w.WriteString(renderMathML(m.Raw, m.Block))      // mathml.go — latex2mathml
    }
    return ast.WalkSkipChildren, nil
}
```

The construct-detection predicate (research Open Question #4, MEDIUM-confidence synthesis — matches the known Chromium MathML-Core gaps):
```go
// detect.go — pure, testable, no I/O.
var fallbackRE = regexp.MustCompile(`\\tag\b|\\label\b|\\begin\{(aligned|align|alignat|cases|array)\}`)
func needsFallback(rawLatex string) bool { return fallbackRE.MatchString(rawLatex) }
```

MathML path (`mathml.go`): call the vendored `git.sr.ht/~mekyt/latex2mathml` (cached; pinned in 03-01) to convert raw LaTeX → a `<math>...</math>` string. Wrap inline vs. block (`display="block"` for `$$`).

Fallback path (`fallback.go`): PNG-ONLY. `codeberg.org/go-latex/latex`'s `drawtex/drawimg` renders to a raster `image.Image`; encode PNG → base64 → `<img src="data:image/png;base64,...">`. This keeps `press.Render` pure (no temp files, no asset server). There is NO SVG canvas in drawtex (research pitfall — do NOT attempt SVG output).
</codebase_examples>

<anti_patterns>
- Do NOT plan an acceptance criterion that says "renders SVG" for the fallback — `codeberg.org/go-latex/latex/drawtex` has only `drawimg` (raster) and `drawpdf` (PDF); NO SVG canvas exists (research pitfall). Baseline fallback is a base64 PNG `<img>`.
- Do NOT over-scope math quality — this is BASELINE (renders common math, degrades heavy constructs). The 8 known latex2mathml converter bugs, KaTeX-parity, and the FINAL fallback-trigger rule are Objective 8's job (ROADMAP decision gate). Do not attempt the converter-hardening pass here.
- Do NOT detect fallback-needed constructs by inspecting a PARTIAL MathML conversion after the fact — pre-scan the RAW LaTeX with the regex (cheap, bounded, targets the known-unsupported classes directly).
- Do NOT write the fallback to disk or fetch anything over the network at render time — embed as a data-URI (keeps press.Render a pure, safe-for-untrusted function).
- Do NOT use raw `\(\)`/`\[\]` delimiters — Marp uses Pandoc-style `$…$`/`$$…$$` (FEATURES.md).
</anti_patterns>
