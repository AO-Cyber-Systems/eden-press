Fill the 04-02 stub — read `--theme-set` paths from cfg (so both flag and config supply them) into raw CSS strings:
```go
// cmd/eden-press/themeset.go
func themeCSS(cmd *cobra.Command) ([]string, error) {
    paths := cfg.Strings("theme-set") // koanf-resolved (flag + config); flag is StringSlice from 04-02
    if len(paths) == 0 { return nil, nil }
    out := make([]string, 0, len(paths))
    for _, p := range paths {
        b, err := os.ReadFile(p)
        if err != nil {
            return nil, fmt.Errorf("theme-set: read %s: %w", p, err)
        }
        out = append(out, string(b))
    }
    return out, nil
}
```
buildOptions (04-02, unchanged) already does `tcss, err := themeCSS(cmd); ... ThemeCSS: tcss`. press.Render (04-01) does the theme.Load+ThemeSet.Add over Options.ThemeCSS and resolves the selected name — so the CLI's job ends at "read files → []string".

Selection flow the user sees:
```
eden-press --theme-set brand.css --theme brand deck.md
# brand.css starts with:  /* @theme brand */  section { color: #d4a853; }
# press.Render registers "brand", resolves --theme "brand", packs its scoped CSS into Output.CSS
```
